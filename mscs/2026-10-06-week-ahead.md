# MSCS Week Ahead — First Run

I can build the weekly plan around the Northeastern MSCS courses discussed: PDP and Information Retrieval. I do not currently have live Canvas/LMS deadlines, current assignment status, exam dates, or this week’s reading list, so none are invented here.

## Highest priority this week

- Capture every confirmed deadline first. Check Canvas/LMS for PDP and Information Retrieval and put all assignments, quizzes, project milestones, readings, and exams due in the next 10–14 days into one list.
- Front-load the course with the nearest coding/project deadline. For programming-heavy work, aim to get a working version at least 48 hours before submission so there is time for debugging and testing.
- Keep Information Retrieval concepts cumulative. Reserve focused study time for the current IR topic and connect each concept to implementation or interview-level intuition rather than leaving all theory for exam week.
- Protect one catch-up block. Keep one 2–3 hour block late in the week unassigned so unfinished work does not spill into the following week.

## Suggested weekly structure

### Monday–Tuesday
- Review both course pages and identify the nearest graded deliverables.
- Start the most difficult coding/project task while there is still buffer.
- Review this week’s IR lecture material and produce concise notes containing definitions, algorithms, assumptions, and complexity where relevant.

### Wednesday–Thursday
- Push the main assignment/project to a complete first version.
- Test edge cases and clean up code/documentation.
- Do active IR practice: derive or explain the current algorithm/concept without notes, then check gaps.

### Friday
- Finish anything due over the weekend or early next week.
- Review instructor/TA feedback from previous submissions and explicitly apply recurring feedback to current work.

### Weekend
- Submit completed work after one final verification pass.
- Preview the next week’s lectures/readings.
- Spend one focused block on interview preparation only after the week’s academic deadlines are under control.

## What should get attention first

Due within 48 hours → blocked team/project work → difficult programming assignment → exam preparation → readings → optional enrichment.

For two tasks with the same deadline, start the one with the greatest uncertainty first.

## Conflict check

The main risk is letting interview preparation or research/work consume the uninterrupted blocks needed for MSCS assignments. Until exact deadlines are available, keep at least two substantial academic deep-work blocks during the week before allocating additional discretionary work.
