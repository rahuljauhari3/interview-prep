# Interview Prep Knowledge Base

This repository stores recurring technical walkthroughs and briefings in Markdown so they are easy to search, review, and version.

## Sections

- `dsa/` — DSA interview walkthroughs
- `system-design/` — system design interview walkthroughs
- `ai-inference/` — AI inference research briefings
- `mscs/` — MSCS weekly planning notes

## File naming

- DSA: `YYYY-MM-DD-<leetcode-number>-<short-slug>.md`
- System Design: `YYYY-MM-DD-<short-slug>.md`
- AI Inference: `YYYY-MM-DD-<short-slug>.md`
- MSCS: `YYYY-MM-DD-week-ahead.md`

Historical scheduled-task outputs are migrated from archived copies and preserved in Markdown wherever possible.
