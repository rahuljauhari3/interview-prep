# DSA Interview Walkthrough — LeetCode 45: Jump Game II

**Difficulty:** Medium  
**Pattern:** Greedy · Implicit BFS Layers  
**Core lesson:** Treat all indices reachable with the current number of jumps as one BFS layer. While scanning that layer, track the farthest index reachable by one more jump.

## 1. Interviewer prompt

Given an array where `nums[i]` is the maximum jump length from index `i`, return the minimum number of jumps needed to reach the last index. You may assume the last index is reachable.

```text
nums = [2,3,1,1,4]
answer = 2
```

One optimal route is `0 -> 1 -> 4`.

## 2. Recognize the pattern

The problem asks for the **minimum number of steps** through an implicit graph:
- each index is a node,
- from index `i`, you can jump to several later indices.

Minimum steps suggests BFS. Explicitly building all edges would be expensive, but the array structure lets us process BFS layers greedily.

## 3. Brute force / BFS baseline

A brute-force recursive search tries every jump from every index and repeats subproblems.

A direct BFS can enqueue every reachable index, but each node may generate many edges, leading to `O(n^2)` work in the worst case.

We can compress each BFS layer to a range.

## 4. Greedy layer idea

Maintain:
- `current_end`: farthest index reachable using the current number of jumps,
- `farthest`: farthest index reachable using one additional jump while scanning the current layer,
- `jumps`: number of completed layers.

Scan from left to right.

At each index:

```text
farthest = max(farthest, i + nums[i])
```

When `i == current_end`, we have finished scanning every position reachable with the current number of jumps. We must take another jump:

```text
jumps += 1
current_end = farthest
```

Stop before processing the last index because once the current layer reaches it, no additional jump is required.

## 5. Dry run

For `[2,3,1,1,4]`:

- Start: `current_end=0`, `farthest=0`, `jumps=0`.
- `i=0`: farthest becomes 2. End of layer -> jump 1, `current_end=2`.
- `i=1`: farthest becomes 4.
- `i=2`: farthest stays 4. End of layer -> jump 2, `current_end=4`.
- Last index is now reachable.

Answer: 2.

## 6. Clean final Python solution

```python
class Solution:
    def jump(self, nums: list[int]) -> int:
        jumps = 0
        current_end = 0
        farthest = 0

        for i in range(len(nums) - 1):
            farthest = max(farthest, i + nums[i])

            if i == current_end:
                jumps += 1
                current_end = farthest

        return jumps
```

No lambda functions are used.

## 7. Complexity

- Time: `O(n)`.
- Auxiliary space: `O(1)`.

## 8. Correctness

Before each layer boundary, every scanned index is reachable with exactly the current number of jumps or fewer. `farthest` records the union of all positions reachable with one additional jump from that layer. Advancing the boundary only after scanning the entire current layer is equivalent to BFS, which guarantees the fewest jumps. Therefore the first layer whose range reaches the last index gives the optimal answer.

## 9. Edge cases and common mistakes

- Single-element array -> 0 jumps.
- First jump already reaches the end -> 1.
- Large values that overshoot the final index are fine.

Common mistakes:
- greedily jumping from each index immediately to the locally farthest destination,
- iterating through the final index and adding one extra jump,
- updating `current_end` before finishing the whole current layer,
- confusing this with Jump Game I, which asks only reachability.

## 10. Interviewer follow-ups

**Why is this BFS?** `current_end` marks the end of the current BFS depth; `farthest` is the next layer's maximum reach.

**What if reachability is not guaranteed?** If `i == current_end` and `farthest == current_end` before reaching the end, progress is impossible.

**Return the actual path?** Store which index first extended the next-layer boundary and reconstruct parent choices.

## 11. What to say aloud

> “I can view indices as nodes in an implicit graph and jumps as edges, so the minimum number of jumps is a BFS depth. I do not need to enqueue every destination. I scan the current reachable range, track the farthest place one more jump could reach, and when I hit the end of the current range I increment the jump count and promote that farthest reach to the next boundary. That is BFS layer processing compressed into O(n) time and O(1) space.”

## 12. Pattern takeaway

```text
Minimum jumps in implicit graph
          ↓
BFS layers
          ↓
Current reachable interval
          ↓
Track farthest next-layer reach
          ↓
Advance boundary once per layer
          ↓
O(n)
```
