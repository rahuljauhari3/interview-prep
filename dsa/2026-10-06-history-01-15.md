## 1. LeetCode 739 — Daily Temperatures

**Difficulty:** Medium  
**Pattern:** Monotonic Stack

Core lesson: When a problem asks for the next greater/smaller element to the left or right, consider a monotonic stack.

### Problem
Given temperatures, return `answer[i]`, the number of days until a warmer temperature. If no warmer day exists, return 0.

Example:

```text
temperatures = [73,74,75,71,69,72,76,73]
answer = [1,1,4,2,1,1,0,0]
```

### Recognize the pattern
For every element, find the next element to its right that is greater. This is a classic next greater element pattern.

### Brute force
For every day, scan right until a warmer day is found.

```python
for i in range(n):
    for j in range(i + 1, n):
        if temperatures[j] > temperatures[i]:
            answer[i] = j - i
            break
```

Time: O(n²)  
Space: O(1) excluding output.

### Optimization intuition
Instead of asking each earlier day to search into the future, reverse the viewpoint: as each new temperature arrives, which unresolved earlier days can it resolve?

Maintain indices of unresolved days in a stack whose temperatures are decreasing. When a warmer temperature arrives, repeatedly pop colder days and set their answer.

### Final solution

```python
class Solution:
    def dailyTemperatures(self, temperatures: list[int]) -> list[int]:
        answer = [0] * len(temperatures)
        stack = []

        for i, temperature in enumerate(temperatures):
            while stack and temperature > temperatures[stack[-1]]:
                previous_day = stack.pop()
                answer[previous_day] = i - previous_day
            stack.append(i)

        return answer
```

**Complexity:** O(n) time, O(n) space.

Common mistakes: storing temperatures instead of indices; using `if` rather than `while`; using `>=` for a strictly warmer condition; assuming the nested loop is O(n²) despite amortized O(n).

## 2. LeetCode 875 — Koko Eating Bananas

**Difficulty:** Medium  
**Pattern:** Binary Search on the Answer

Given piles of bananas and `h` hours, return the minimum integer eating speed `k` that lets Koko finish all piles within `h` hours.

For a candidate speed `k`, hours required are `sum(ceil(pile / k))`.

Brute force tries every speed from 1 to `max(piles)`, taking O(n·M), where M is the largest pile.

The key observation is monotonic feasibility: once a speed works, every larger speed also works. Search for the first true value.

```python
class Solution:
    def minEatingSpeed(self, piles: list[int], h: int) -> int:
        left = 1
        right = max(piles)

        def can_finish(k):
            hours = 0
            for pile in piles:
                hours += (pile + k - 1) // k
                if hours > h:
                    return False
            return True

        while left < right:
            mid = left + (right - left) // 2
            if can_finish(mid):
                right = mid
            else:
                left = mid + 1

        return left
```

**Complexity:** O(n log M) time, O(1) space.

Recognition rule: if asked for the minimum/maximum X such that `condition(X)` is true, and the condition is monotonic, binary-search the answer space.

## 3. LeetCode 207 — Course Schedule (Kahn’s Algorithm)

**Difficulty:** Medium  
**Pattern:** Directed Graph + Topological Sort

`[a,b]` means course `b` must be completed before course `a`, so the edge is `b -> a`. A valid course order exists iff the directed graph has no cycle.

`indegree[v]` is the number of prerequisites still required by `v`. Any node with indegree zero can be processed immediately. Remove its outgoing dependencies and enqueue nodes that reach indegree zero.

```python
from collections import deque

class Solution:
    def canFinish(self, numCourses: int, prerequisites: list[list[int]]) -> bool:
        graph = [[] for _ in range(numCourses)]
        indegree = [0] * numCourses

        for course, prerequisite in prerequisites:
            graph[prerequisite].append(course)
            indegree[course] += 1

        queue = deque()
        for course in range(numCourses):
            if indegree[course] == 0:
                queue.append(course)

        completed = 0
        while queue:
            course = queue.popleft()
            completed += 1

            for next_course in graph[course]:
                indegree[next_course] -= 1
                if indegree[next_course] == 0:
                    queue.append(next_course)

        return completed == numCourses
```

**Complexity:** O(V + E) time and O(V + E) space.

## 4. LeetCode 322 — Coin Change

**Difficulty:** Medium  
**Pattern:** Dynamic Programming / Unbounded Knapsack

At each remaining amount, brute force tries every coin, creating repeated subproblems. Define `dp[x]` as the minimum coins required to make amount `x`.

Base case: `dp[0] = 0`. Transition: `dp[x] = min(dp[x], 1 + dp[x - coin])` for each coin ≤ x.

```python
class Solution:
    def coinChange(self, coins: list[int], amount: int) -> int:
        dp = [amount + 1] * (amount + 1)
        dp[0] = 0

        for current_amount in range(1, amount + 1):
            for coin in coins:
                if coin <= current_amount:
                    dp[current_amount] = min(
                        dp[current_amount],
                        1 + dp[current_amount - coin]
                    )

        return -1 if dp[amount] == amount + 1 else dp[amount]
```

**Complexity:** O(A·C) time and O(A) space.

Greedy can fail: with coins `[1,3,4]` and amount `6`, greedy gives `4+1+1`, but optimal is `3+3`.

## 5. LeetCode 3 — Longest Substring Without Repeating Characters

**Difficulty:** Medium  
**Pattern:** Sliding Window + Hash Map

Maintain a valid window `[left, right]` containing only unique characters. Store the last seen index of each character. On a duplicate, move `left` just far enough forward:

`left = max(left, last_seen[char] + 1)`.

```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        last_seen = {}
        left = 0
        best = 0

        for right, char in enumerate(s):
            if char in last_seen:
                left = max(left, last_seen[char] + 1)

            last_seen[char] = right
            best = max(best, right - left + 1)

        return best
```

**Complexity:** O(n) time and O(min(n, alphabet size)) space.

Classic bug: on `abba`, assigning `left = last_seen[char] + 1` without `max` can move the left pointer backward.

## 6. LeetCode 560 — Subarray Sum Equals K

**Difficulty:** Medium  
**Pattern:** Prefix Sum + Hash Map

Negative values make ordinary sliding window unreliable. Let `current_sum` be the prefix sum through the current index. We need an earlier prefix `previous_sum` such that:

`current_sum - previous_sum = k`, so `previous_sum = current_sum - k`.

Count frequencies of prior prefix sums, starting with `prefix_count[0] = 1`.

```python
from collections import defaultdict

class Solution:
    def subarraySum(self, nums: list[int], k: int) -> int:
        prefix_count = defaultdict(int)
        prefix_count[0] = 1

        current_sum = 0
        result = 0

        for num in nums:
            current_sum += num
            result += prefix_count[current_sum - k]
            prefix_count[current_sum] += 1

        return result
```

**Complexity:** O(n) time and O(n) space.

## 7. LeetCode 56 — Merge Intervals

**Difficulty:** Medium  
**Pattern:** Sorting + Greedy

Sort by start time. Compare each interval only with the last merged interval. If `current_start <= last_end`, extend the merged interval; otherwise append a new one.

```python
class Solution:
    def merge(self, intervals: list[list[int]]) -> list[list[int]]:
        intervals.sort(key=lambda interval: interval[0])
        merged = []

        for start, end in intervals:
            if not merged or start > merged[-1][1]:
                merged.append([start, end])
            else:
                merged[-1][1] = max(merged[-1][1], end)

        return merged
```

**Complexity:** O(n log n) time; sorting dominates.

## 8. LeetCode 721 — Accounts Merge

**Difficulty:** Medium  
**Pattern:** Union-Find / Disjoint Set Union

If account A shares an email with B and B shares an email with C, all three belong to the same connected component. Map each email to the first account index that owns it; union later accounts that share the email.

```python
from collections import defaultdict

class Solution:
    def accountsMerge(self, accounts: list[list[str]]) -> list[list[str]]:
        n = len(accounts)
        parent = list(range(n))
        size = [1] * n

        def find(x):
            if parent[x] != x:
                parent[x] = find(parent[x])
            return parent[x]

        def union(a, b):
            root_a = find(a)
            root_b = find(b)
            if root_a == root_b:
                return

            if size[root_a] < size[root_b]:
                root_a, root_b = root_b, root_a

            parent[root_b] = root_a
            size[root_a] += size[root_b]

        email_owner = {}
        for account_index, account in enumerate(accounts):
            for email in account[1:]:
                if email in email_owner:
                    union(account_index, email_owner[email])
                else:
                    email_owner[email] = account_index

        grouped = defaultdict(list)
        for email, account_index in email_owner.items():
            root = find(account_index)
            grouped[root].append(email)

        result = []
        for root, emails in grouped.items():
            result.append([accounts[root][0]] + sorted(emails))

        return result
```

DSU operations are effectively near-constant amortized; sorting output emails dominates.

## 9. LeetCode 42 — Trapping Rain Water

**Difficulty:** Hard  
**Pattern:** Two Pointers

Water above position `i` is `min(max_left[i], max_right[i]) - height[i]`.

With two pointers, maintain running `left_max` and `right_max`. If `left_max <= right_max`, water at the left pointer is already determined; otherwise process the right pointer.

```python
class Solution:
    def trap(self, height: list[int]) -> int:
        left = 0
        right = len(height) - 1
        left_max = 0
        right_max = 0
        water = 0

        while left <= right:
            left_max = max(left_max, height[left])
            right_max = max(right_max, height[right])

            if left_max <= right_max:
                water += left_max - height[left]
                left += 1
            else:
                water += right_max - height[right]
                right -= 1

        return water
```

**Complexity:** O(n) time, O(1) space.

## 10. LeetCode 76 — Minimum Window Substring

**Difficulty:** Hard  
**Pattern:** Sliding Window + Frequency Map

Return the smallest substring of `s` containing every character of `t`, including duplicates. Expand right until valid, then shrink left while remaining valid and record the smallest window.

```python
from collections import Counter, defaultdict

class Solution:
    def minWindow(self, s: str, t: str) -> str:
        if not s or not t:
            return ""

        need = Counter(t)
        window = defaultdict(int)
        required = len(need)
        formed = 0
        left = 0

        best_length = float("inf")
        best_left = 0

        for right, char in enumerate(s):
            window[char] += 1

            if char in need and window[char] == need[char]:
                formed += 1

            while formed == required:
                length = right - left + 1
                if length < best_length:
                    best_length = length
                    best_left = left

                left_char = s[left]
                if left_char in need and window[left_char] == need[left_char]:
                    formed -= 1

                window[left_char] -= 1
                left += 1

        if best_length == float("inf"):
            return ""

        return s[best_left:best_left + best_length]
```

**Complexity:** O(len(s) + len(t)) time.

## 11. LeetCode 207 — Course Schedule (DFS 3-State Coloring)

**Difficulty:** Medium  
**Pattern:** Directed Graph + DFS Cycle Detection

Use three states: `0 = UNVISITED`, `1 = VISITING`, `2 = VISITED`. Reaching a VISITING node means a back edge and therefore a directed cycle.

```python
class Solution:
    def canFinish(self, numCourses: int, prerequisites: list[list[int]]) -> bool:
        graph = [[] for _ in range(numCourses)]
        for course, prerequisite in prerequisites:
            graph[prerequisite].append(course)

        state = [0] * numCourses

        def has_cycle(course):
            if state[course] == 1:
                return True
            if state[course] == 2:
                return False

            state[course] = 1
            for next_course in graph[course]:
                if has_cycle(next_course):
                    return True

            state[course] = 2
            return False

        for course in range(numCourses):
            if has_cycle(course):
                return False

        return True
```

**Complexity:** O(V + E) time and space.

## 12. LeetCode 208 — Implement Trie

**Difficulty:** Medium  
**Pattern:** Trie / Prefix Tree

Each node stores `children` and `is_end`. `is_end` distinguishes a complete inserted word from a path that merely exists as a prefix.

```python
class TrieNode:
    def __init__(self):
        self.children = {}
        self.is_end = False

class Trie:
    def __init__(self):
        self.root = TrieNode()

    def insert(self, word: str) -> None:
        node = self.root
        for char in word:
            if char not in node.children:
                node.children[char] = TrieNode()
            node = node.children[char]
        node.is_end = True

    def search(self, word: str) -> bool:
        node = self._find_node(word)
        return node is not None and node.is_end

    def startsWith(self, prefix: str) -> bool:
        return self._find_node(prefix) is not None

    def _find_node(self, text: str):
        node = self.root
        for char in text:
            if char not in node.children:
                return None
            node = node.children[char]
        return node
```

For a string/prefix of length L, insert/search/prefix query are O(L).

## 13. LeetCode 743 — Network Delay Time

**Difficulty:** Medium  
**Pattern:** Weighted Graph + Dijkstra

Weighted graph + shortest/minimum travel time + non-negative weights strongly suggests Dijkstra. BFS minimizes edge count, not weighted cost.

```python
from collections import defaultdict
import heapq

class Solution:
    def networkDelayTime(self, times: list[list[int]], n: int, k: int) -> int:
        graph = defaultdict(list)
        for source, target, weight in times:
            graph[source].append((target, weight))

        dist = [float("inf")] * (n + 1)
        dist[k] = 0
        min_heap = [(0, k)]

        while min_heap:
            current_dist, node = heapq.heappop(min_heap)
            if current_dist > dist[node]:
                continue

            for neighbor, weight in graph[node]:
                new_dist = current_dist + weight
                if new_dist < dist[neighbor]:
                    dist[neighbor] = new_dist
                    heapq.heappush(min_heap, (new_dist, neighbor))

        answer = max(dist[1:])
        return -1 if answer == float("inf") else answer
```

**Complexity:** O((V + E) log V) time and O(V + E) space.

## 14. LeetCode 84 — Largest Rectangle in Histogram

**Difficulty:** Hard  
**Pattern:** Monotonic Increasing Stack

Choose a bar as the rectangle height. It can extend left and right until the first shorter bar. Maintain indices of nondecreasing heights. When a smaller incoming height appears, it becomes the first smaller bar on the right of taller stack entries.

```python
class Solution:
    def largestRectangleArea(self, heights: list[int]) -> int:
        stack = []
        max_area = 0

        for i in range(len(heights) + 1):
            current_height = heights[i] if i < len(heights) else 0

            while stack and heights[stack[-1]] > current_height:
                height = heights[stack.pop()]
                if stack:
                    width = i - stack[-1] - 1
                else:
                    width = i
                max_area = max(max_area, height * width)

            stack.append(i)

        return max_area
```

Each index is pushed once and popped once: O(n) time, O(n) space.

## 15. LeetCode 312 — Burst Balloons

**Difficulty:** Hard  
**Pattern:** Interval Dynamic Programming

Choosing the first balloon is difficult because its neighbors depend on previous removals. Instead, choose which balloon is burst last inside an interval.

Add sentinels: `[1] + nums + [1]`.

Define `dp[left][right]` as the maximum coins obtainable by bursting all balloons strictly between `left` and `right`, while those boundary balloons remain intact.

If `k` is last:

`dp[left][right] = max(dp[left][k] + dp[k][right] + balloons[left] * balloons[k] * balloons[right])`.

### Memoized solution

```python
from functools import cache

class Solution:
    def maxCoins(self, nums: list[int]) -> int:
        balloons = [1] + nums + [1]

        @cache
        def solve(left, right):
            if left + 1 == right:
                return 0

            best = 0
            for k in range(left + 1, right):
                coins = (
                    solve(left, k)
                    + solve(k, right)
                    + balloons[left] * balloons[k] * balloons[right]
                )
                best = max(best, coins)

            return best

        return solve(0, len(balloons) - 1)
```

### Bottom-up solution

```python
class Solution:
    def maxCoins(self, nums: list[int]) -> int:
        balloons = [1] + nums + [1]
        n = len(balloons)
        dp = [[0] * n for _ in range(n)]

        for length in range(2, n):
            for left in range(n - length):
                right = left + length
                for k in range(left + 1, right):
                    dp[left][right] = max(
                        dp[left][right],
                        dp[left][k]
                        + dp[k][right]
                        + balloons[left] * balloons[k] * balloons[right]
                    )

        return dp[0][n - 1]
```

**Complexity:** O(n³) time and O(n²) space.

Recognition rule: if removing elements changes adjacency and forward state is messy, consider choosing the final operation instead of the first.
